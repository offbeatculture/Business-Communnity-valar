# scripts/ — operational + report-generation tools

Local utilities that aren't part of the runtime app. Run them with `node` or `npx tsx` from the repo root. They depend on `.env.local` for Supabase credentials.

## Report generation (interim manual flow)

While the new automated report pipeline is being built (Mac daemon + Claude Max + Chrome-headless renderer), reports are generated by hand for each new submission. These two scripts are the first half of that flow.

### `pull-submission.mjs`

Pulls a founder's most recent fully-submitted long-form audit from Supabase and writes the raw JSON to `/tmp/pulled-submission.json`.

```bash
node scripts/pull-submission.mjs <email>

# example
node scripts/pull-submission.mjs founder@example.com
```

Picks the submission with `submitted_at != null` AND the most answers (so an abandoned 22-answer draft never wins over a completed 96-answer one).

### `resolve-answers.ts`

Reads `/tmp/pulled-submission.json` and resolves every raw answer value (`"job_title"`, `"7_30"`, etc.) into its human-readable label from the question bank. Writes the result to `/tmp/resolved-answers.json`.

```bash
npx tsx scripts/resolve-answers.ts
```

The resolved JSON is what gets handed to Claude (or to you) for writing the report prose. Each answer becomes:

```json
{
  "q19_business_naming": {
    "force": "identity",
    "question_text": "When a stranger asks 'what business are you in?'...",
    "helper": "Pick the answer closest to how you actually describe it.",
    "value": "job_title",
    "label": "My job title (e.g. 'I'm a CA / coach / dentist / fabricator')",
    "score": 1,
    "confidence": null
  }
}
```

## Full manual report flow (today's process)

1. `node scripts/pull-submission.mjs founder@example.com` → `/tmp/pulled-submission.json`
2. `npx tsx scripts/resolve-answers.ts` → `/tmp/resolved-answers.json`
3. Open a Claude Code session and paste the resolved JSON + a reference to `lib/report/templates/scale-code-diagnostic-v1/README.md` (the data-shape contract) + `source.md` (the reference report for Ofbc Coach). Ask Claude to produce a new report markdown for this founder.
4. Hand-edit `lib/report/templates/scale-code-diagnostic-v1/template.html` with the new content (or build a templated version — see template README open items).
5. Render to PDF with Chrome headless (command in the template README).
6. Upload the PDF via the admin UI manual approval flow (forthcoming).

Once the daemon ships, steps 3-6 collapse into a single automated job.
